# vinalla.js
외부 의존성이 없이 바닐라 자바스크립트 기반으로 개발중인 경량 웹게임 엔진.

## 개발 환경
- Windows 11 Pro
- VSCode 1.111.0
	- Gemini Code Assist
	- Korean Language Pack for VisualStudio Code
	- Live Server
	- Task Explorer   
- Node.js v24.14.0
	- jsdoc (API 도큐먼트 생성 도구)   
	- esbuild (라이브러리 번들링 도구)

## 작업 스펙
- 외부 의존성 없는 바닐라 자바스크립트.   
- 경량 게임 프레임워크.   
- JSDoc 기반의 타입 힌팅 및 문서화.
